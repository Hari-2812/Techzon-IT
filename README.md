# Techzon — Digital Engineering & Technology Solutions

Techzon is a modern digital engineering and technology solutions website built to showcase software development services, technology expertise, real-world projects, and digital solutions for businesses.

## Features

- Premium responsive enterprise website
- Modern light-theme UI
- 3D animated digital globe
- Interactive technology stack visualization
- Project showcase
- LMS System case study
- WhatsApp CRM Dashboard case study
- Services showcase
- Engineering process / lifecycle visualization
- About section
- Contact form
- Newsletter subscription
- Responsive mobile navigation
- Scroll-to-top behavior
- SEO metadata
- Accessible interactive components
- Responsive layouts across desktop, tablet, and mobile

## Featured Projects

### LMS System
A full-stack Learning Management System designed to manage students, courses, enrollment, live classes, recorded sessions, payments, assignments, quizzes, progress, mentors, and certificates.

**Technology:**
React, Node.js, Express.js, MongoDB, Tailwind CSS, JWT, Razorpay, Socket.IO, Google Meet

### WhatsApp CRM Dashboard
A customer engagement and WhatsApp CRM platform designed to manage contacts, campaigns, templates, scheduling, customer messaging, and campaign tracking through a centralized dashboard.

**Technology:**
React, Node.js, Express.js, MongoDB, Tailwind CSS, JWT, WhatsApp Cloud API, Webhooks
